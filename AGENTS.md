**FORBIDDEN**: Do NOT use `drizzle-kit generate` or `drizzle-kit migrate` or any migration scripts.
**PREFERRED**: ALWAYS use `npm run db:push` (or `drizzle-kit push`) to sync the database schema.

This project is in active development and there is no need for backwards compatibility or preserving migration histories. Always push schema changes directly.
